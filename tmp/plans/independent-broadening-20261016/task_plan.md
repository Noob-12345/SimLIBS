# 静态展宽与自吸收解耦

## 目标
允许 self_absorption=False 时独立启用 Stark 展宽，静态仪器高斯展宽也可单独关闭，保留旧调用默认结果。直接修改用户当前目录，保留已有 README 改写及源码中文注释。

## 接口与约束
- 主类/批量接口末尾新增 stark_broadening=None、instrument_broadening=None，保持现有位置参数兼容。
- static 未显式指定 Stark 时沿用自吸收开关；仪器选项默认使用旧普通高斯行为或旧自吸收配置中的开关。
- 明确 self_absorption=True 且 stark_broadening=False 时在请求前报错。当前公式依赖内禀 Stark FWHM，不使用猜测系数或仪器宽度补替。
- stark-only 保留 NIST 面积，不计算吸收布居/光学厚度，tau=0、SA=1；不伪造零光程。
- 两种展宽均关闭时，将离散线面积投到输出网格，保持梯形积分面积与一阶矩；同波长跃迁贡献累加。
- dynamic 继续使用浏览器结果，忽略本地物理/展宽配置。
- 用户既有严格逐线系数来源要求继续有效；本次不实现 STARK-B 自动查询。
