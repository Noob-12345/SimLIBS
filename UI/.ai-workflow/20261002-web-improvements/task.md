# Web五项改进：原Herdr三角色顺序执行

用户已授权直接逐项实现：提高光谱显示采样；首页比例/上下滚动；元素正确大小写Fe而非FE；配比自动保持100%，编辑前项或末项都自动调整最后元素并提示超额；加入NIST photon flux / energy flux。
主要目标为当前web/实际页面，保留用户刚新增的黑红/亮色风格、Canvas动效和三键交互。沿用simlibs-ui会话、w1:t1原libs_planner/coder/reviewer，不启动新agent/pane/终端窗口。planner负责规划及持续协调，不写业务代码；原coder实现，停止后原reviewer独立验收，发现问题交同一coder返工。
使用既有Python3.10与依赖；本地服务当前8517/PID10504。服务重启只在确认进程命令属于本项目后进行，隐藏启动，不影响其他服务和用户浏览器；源库simLIBS-2.0.3保持不动。
配比假设：最后一项为100减前项和的余额；不足时自动补足末项，超额时提示并缩减末项，末项降0仍不足时把本次编辑前项限制在其他前项剩余额度，避免负值。空/NaN/无穷/负输入仍明确拒绝，不转0或请求NIST。
