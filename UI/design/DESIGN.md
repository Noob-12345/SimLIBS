# simLIBS Studio · 网页界面设计规范

> 本文档描述 `index.html` 交互原型所展示的设计系统，以及后续用 NiceGUI（或同类浏览器方案）落地时的映射建议。
> 原型为纯 HTML/CSS/JS 自包含文件，双击即可在浏览器打开，无需安装任何东西；未改动 UI 目录任何现有程序文件。

## 1. 设计目标

- **图表是主角**：光谱绘图区占据最大视觉面积，参数面板退居次要位置。
- **动态感**：模拟运行有真实进度条 + 逐行滚动的任务日志（对应现有 `events.jsonl` 事件流）；滑块拖动即时重绘；扫描页可播放帧动画；操作结果用 toast 反馈。
- **可追溯性外显**：来源证据（NIST HTTP 状态、行数、SHA256、耗时）以 chip 徽章形式常驻结果区，呼应现有"每个任务可追溯"的设计。
- **信息密度适中**：桌面优先（≥1280px 宽），沿用现有三功能页 + 设置 + 任务记录的信息架构。

## 2. 设计令牌

### 主题：Plasma Dark（默认，黑红配色）+ Light 变体

| 令牌 | Dark（黑红） | 用途 |
|---|---|---|
| `--bg` | `#0a0b0e` | 页面底色（近黑） |
| `--card` | `#131418` | 卡片表面 |
| `--border` / `--border2` | `#26282f` / `#3d3036` | 描边（hover 带暖红调） |
| `--text` / `--muted` | `#f0ebed` / `#a59da2` | 主文字 / 次要文字（暖灰） |
| `--accent` | `#ef4444`（红） | 主操作、图表主线、选中态 |
| `--accent2` | `#f97316`（橙红） | 渐变终点、离子谱线用 `--chart-ion:#f59e0b` |
| `--good / --warn / --bad / --info` | `#34d399 / #fbbf24 / #fb7185 / #60a5fa` | 成功 / 警告 / 错误 / 信息（错误用亮玫瑰红，与主红区分） |

- 主按钮与 logo 使用 `accent → accent2` 的 135° 渐变（红→橙，"等离子体热辐射"意象）；光晕统一走 `--glow / --glow-strong / --flash-ring` 变量。
- Light 主题保持青色方案（`--accent:#0891b2`），图表系列色：raw 暖灰点线（次要），主线红/青（按主题），ion 琥珀/紫（按主题）。
- 字体：正文 `Inter / Segoe UI / system-ui`；所有数值（参数、坐标、ID、SHA）用等宽字体 `JetBrains Mono / Consolas`——科学工具的可信感来自数字排版。
- 圆角：卡片 14px，控件 8–9px，胶囊 99px。
- 动效：页面切换 320ms 淡入上移；进度条带 shimmer 流光；toast 右下滑入；卡片 hover 微亮。所有动画 ≤350ms，不拖沓；图表另有左键框选放大 / 中键平移 / 右键复原三键交互（见第 6 节）。

## 3. 布局结构

```
┌──────────┬────────────────────────────────────────────┐
│ 侧边栏    │  顶栏：页标题 + NIST 状态胶囊 + 运行状态 + 主题切换 │
│ 236px    ├────────────────────────────────────────────┤
│          │                                            │
│ 品牌 logo │   内容区（max-width 1460 居中）               │
│ 模拟      │   ┌─ 参数面板 340px ─┬─ 结果区（自适应）─┐     │
│ · 单次    │   │ 滑块/输入/配比   │ 光谱图 + 图例      │     │
│ · 批量    │   │ 预设/开始按钮    │ 元数据 chips      │     │
│ · 扫描    │   │                 │ 导出按钮          │     │
│ 记录与环境 │   │                 │ 任务日志 + 进度条  │     │
│ · 任务记录│   └─────────────────┴──────────────────┘     │
│ · 设置    │                                            │
│ 引擎状态卡 │                                            │
└──────────┴────────────────────────────────────────────┘
```

- 侧边栏底部放"引擎状态卡"：NIST 可达性、Python worker 版本、ChromeDriver 匹配状态、当前引擎忙/闲——把现有 `--diagnose` 的关键信息常驻化。
- 顶栏运行中显示全局运行胶囊（含百分比），任何页面都能看到后台任务状态。

## 4. 关键交互设计（对应现有功能契约）

| 现有功能 | 原型中的表达 |
|---|---|
| 配比总和必须 100% | 配比行内联百分比条 + 底部总和校验条（绿✓/红✗），非法时「开始模拟」按钮点击即拦截并 toast 报错 |
| 预设只填参数不联网 | 预设按钮点击 → 参数填充 + toast 明示"未联网" |
| R 是分辨率不是步长 | 标签直接写明"光谱分辨率 R（仪器分辨率，非重采样步长）" |
| static 无 ion 谱 | 切到 static 时 ion 图例自动隐藏 |
| 主动重采样开关 | 独立 switch，对应"只有主动归一化/重采样才改变行为"的契约 |
| 任务日志与追溯 | 运行时日志框逐行显示 worker/adapter/nist/parse/interp/done 各阶段（对应 `events.jsonl`），完成后显示来源 chips |
| 取消保留上次结果 | 运行中按钮变"取消模拟"；取消后日志提示"已保留上一次成功图谱" |
| 批量状态机 | 样本行状态标签（排队/运行中带内联进度/完成/失败可重试）+ 顶部统计卡 |
| 扫描播放不联网 | 播放/暂停/逐帧/进度滑条 + 帧信息实时显示；"预览扫描值"展示采样值 chips |
| 失败/取消/部分 | 任务记录页用彩色状态标签区分 成功/失败(附 error.json)/已取消 |
| 图表三键交互 | 左键框选→选区放大（y 轴按可见数据自适应）；中键拖动→平移（数据范围钳制）；右键→复原。视窗与形变动画/十字光标/SSE 重绘兼容，数据范围变化（新结果/新预设）时视窗自动失效。图表右下角有操作提示条 |

## 5. 落地映射（NiceGUI 方案）

原型展示的每个元素在 NiceGUI 里都有直接对应物，后端逻辑（`models/adapter/jobs/operations/worker/storage`）完全不需要改动：

| 原型元素 | NiceGUI 组件 |
|---|---|
| 侧边栏 / 顶栏 | `ui.left_drawer` / `ui.header`，`app.dark_mode(True)` |
| 页面切换 | `ui.tabs` + `ui.tab_panels`（或 `ui.sub_pages`） |
| 参数滑块 / 输入 | `ui.slider` / `ui.number` / `ui.select` / `ui.switch` |
| 光谱图 | `ui.echart`（ECharts）：line + dataZoom 缩放 + tooltip 十字光标 + 渐变 areaStyle；也可继续用 matplotlib + `ui.matplotlib`，但 ECharts 的交互上限更高 |
| 样本表 / 任务表 | `ui.table`（自带分页、行内进度、状态徽章插槽） |
| 任务日志 | `ui.log`（自带自动滚动、行数上限） |
| 进度条 | `ui.linear_progress`，由 worker 事件流经 WebSocket 推送驱动 |
| toast | `ui.notify` |
| 状态胶囊 | `ui.badge` / `ui.chip` |

落地要点：

1. **事件桥**：现有 worker 已产生 `events.jsonl`，把事件回调同时推给 `ui.notify` / `ui.log` / 进度条即可，无需轮询。
2. **启动方式**：`ui.run(native=True)` 打包成独立窗口（pywebview），或浏览器访问 `http://localhost:8080`；单用户本地使用，无需鉴权。
3. **图表数据量**：预览沿用现有契约（抽样 ≤1500 点）传给 ECharts；全量数据仍走 CSV 导出。
4. **依赖**：`pip install nicegui`（含 ECharts 支持），仅新增于 UI 侧，不触碰源库。

## 6. 动效规范（已在 web/ 前端实现）

所有动效 ≤700ms、统一 easeOut 缓动，且尊重系统"减少动态效果"设置（`prefers-reduced-motion` 时全部降级为即时呈现）：

| 动效 | 触发时机 | 参数 |
|---|---|---|
| 光谱描线（reveal） | 任务完成、扫描结果首帧 | 700ms，左→右揭示，raw 点随线出现 |
| 曲线形变（morph） | 拖动 Te/Ne/R 滑块、扫描播放/拖帧 | 150ms，逐点插值；波长范围变化时自动退化为即时 |
| 徽章层叠（chipIn） | 结果来源徽章出现 | 350ms + 每枚 70ms 延迟 |
| 卡片光环（cardFlash） | 任务完成 | 1s 扩散圆环，青色 |
| 数字滚动（countUp） | 批量统计卡 | 650ms easeOut |
| 卡片入场（cardIn） | 页面切换 | 450ms 上浮，右列延迟 80ms |
| 呼吸灯 | 运行胶囊、状态点 | 1.6–2.4s 循环 |
| 按压反馈 | 按钮/播放键/删除 | scale 0.88–0.96 |

实现位于 `web/static/app.js` 的 `present()`（描线/形变/即时三模式调度，带令牌中断与"当前显示值"续接，悬停十字光标读取形变中的实时值）与 `countUp()/flashCard()`。

## 7. 原型范围说明

- 原型中的光谱由简化的洛伦兹峰 + 噪声模型即时合成，仅用于演示视觉与交互，**不是真实 NIST 数据**；图内已标注"示意预览"。
- 批量表、任务记录、宽表预览均为静态示意数据。
- 后续真实程序接入时，按本文档第 4 节的契约逐项对齐即可。
